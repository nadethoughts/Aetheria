# Session 08 Temporary Character Build Notes

All characters use the local Nimble-Rules project as the rules source.
Current Markdown controls unless a later controlling entry is recorded in
`Errata and Change Log.md`. The original ULT PDF was preserved unchanged.

## Accessible handoff revision

- Each character now has three A4 pages: the filled ULT sheet, a Play Guide,
  and separate Ability Cards.
- The short rules use 10.2 pt body text on the guide pages, bold ability
  titles, and bold italics for triggers, costs, ranges, and use limits.
- Each decision is isolated in a bordered card with a short bullet list.
  Long continuous rules blocks were removed.
- The original portrait circle is in the upper-left of the ULT A4 layout;
  each sheet now fills that circle with a character portrait.
- The six portraits are retained in `portraits/` so they can be reused.

## Portrait generation

- Mode: Generate.
- Use case: stylized fantasy character-sheet portraits.
- Shared prompt direction: square, chest-up, painterly storybook realism,
  circular-crop safe, readable at small print size, cool ice-blue/charcoal
  mountain palette, no text, border, watermark, gore, or caricature.
- Character-specific details: Skritch as a betrayed black-scaled kobold
  scout; Da Long as a blue-painted Cloud Seer griffon rider; Feng Rui as a
  weathered pass warden; Cai Lin as a practical healer with a spirit bird;
  Jian Bo as a mountain quartermaster with rope and greatmaul; Mei Rong as an
  older memory keeper with beads, drum, and wind motifs.

## Shared build rules

- Level 3: 4 level-1 skill points plus 1 at levels 2 and 3 (6 assigned points).
- Level-up HP: roll the class Hit Die with advantage; the two selected gains are shown below.
- Hit Dice: normally 3; Survivalist grants Da Long a fourth.
- Starting wealth ceiling: 150 gp at level 3. Every loadout is at or below that ceiling.
- Core quick rules use Assess DC 10, Help as a reroll, Hiding DC 10, and the latest recorded spell corrections.
- Feng Rui uses the latest recorded Shield Expert update from the project errata.
